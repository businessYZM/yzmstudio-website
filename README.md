# YZM Studio Website

Static responsive website prepared for deployment to Vercel or Cloudflare Pages.

## Vercel quick deployment
1. Create a free Vercel account.
2. Choose Add New > Project.
3. Upload this folder through a GitHub repository, or use Vercel CLI.
4. No framework preset or build command is required.
5. Set Output Directory to `.` if requested.
6. Add `yzmstudio.com` under Project Settings > Domains and follow the DNS instructions.

## Cloudflare Pages quick deployment
1. Open Cloudflare Dashboard > Workers & Pages.
2. Create application > Pages.
3. Use Direct Upload or connect a Git repository.
4. Upload the files in this folder.
5. Add the custom domain under the Pages project's Custom domains settings.

## Before launch
- Replace/add social media links when the LinkedIn company page is available.
- Consider using a form provider if you want a web contact form instead of mailto.
- Compress or replace image assets if desired.
